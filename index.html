    开课与连接

    第一次使用，需要准备什么？

    选一个数学知识点或题目，写清你想讲什么，然后点「开始讲课」。课堂里由你先开口讲解，AI 学生随后追问。

    如果还没连接模型，点右上角「设置」填入自己的 API Key，或直接使用课堂共享代理。

    没有 API Key 也能用吗？

    可以。只要代理地址可用，留空 API Key 也能开课。共享代理有额度和频率限制；填自己的 Key 会更稳定。

    为什么提示连接失败？

    先检查 API Key、模型名和余额。如果使用自定义 Base URL，服务商需要支持浏览器跨域（CORS）。换成课堂共享代理通常最省事。

    401 / 403 多半是 Key 或模型权限问题；429 是请求太频繁或额度用完了。

    图片题应该用哪个模型？

    默认的 Qwen3-VL 系列支持图片。DeepSeek V3 只支持文字；如果上传图片后提示不支持，请在设置里换回支持视觉的模型。

    AI 学生与追问

    为什么 AI 学生不回答我的问题？

    这间教室的规则是：你是老师，AI 只当学生。它不会给答案、不会替你计算，也不会判断对错，只会从你刚说的话里提出疑问。

    如果它开场只说「老师，我准备好了」，那是在等你先讲。

    人设和追问强度有什么区别？

    人设决定它关注什么，例如刨根问底型会追规则边界，粗心易错型会暴露常见误区。追问强度决定它问得多紧。

    两处都可以在首页或课堂顶部切换；一节课内学科会锁定，避免混着讲。

    它一直追问同一个点，正常吗？

    正常。说明它还没从你的讲解里听到足够清楚的依据。可以补一个具体例子、反例或步骤依据，再继续讲。

    如果确实卡住了，点「我卡住了」留下卡点，课后报告会把它算进诊断。

    课堂操作

    怎么发送消息？

    点发送按钮，或按 Ctrl + Enter（Mac 上是 ⌘ + Enter）。Shift + Enter 换行。

    卡住了怎么办？

    课堂右下角的悬浮控制条里有「我卡住了」。写下卡在哪一步，它会作为卡点插在当前消息后面，也会进入课后诊断。

    旁边的草稿板可以先列思路，支持 LaTeX 预览；手机上从「草稿板」按钮打开侧边抽屉。

    发错了，能撤回上一轮吗？

    可以。课堂顶部有「撤回上一轮」，会移除你最后一条可见消息和它后面的 AI 回复，并把文字和图片放回输入框。

    如果撤回后课堂里已经没有你的讲解，AI 学生会回到等你先开口的状态。

    图片、手写和语音怎么用？

    题目图片可以点选、粘贴或拖进首页输入区；也可以先识别成文字再修改。课堂消息支持最多 4 张图。

    手写板适合画图、列竖式和写公式；语音输入依赖浏览器的 Web Speech API，不支持时会自动隐藏。

    报告与档案

    诊断报告是怎么打分的？

    AI 老师会从概念掌握、逻辑与步骤、表达清晰度、回应追问、知识迁移五个维度评分，并给出证据、薄弱点和下一步练习。

    报告是学习提示，不是考试判分；证据不足时会标出低证据，不硬编结论。

    学习档案里有什么？

    每节课的主题、轮数、人设、对话回放和诊断报告都会保存。档案顶部还有时间范围筛选、学习热力图、连续天数和互动习惯。

    可以按学科、题目来源筛选，也能多选后批量删除。

    怎么找到报告里的原话？

    报告里的「查看证据」会打开课堂回放，并定位到对应消息。档案里的历史课时也能直接回放。

    数据与隐私

    我的 Key 和课堂数据存在哪里？

    全部只保存在当前浏览器的 localStorage / IndexedDB，不会上传到本站服务器。API Key 只会发往你选择的模型服务商或共享代理。

    无痕模式、清理浏览器数据或换设备都会丢失本地数据，请定期导出 JSON 备份。

    导出的数据包含 API Key 吗？

    不包含。设置里的「导出全部 JSON」会自动移除 API Key；题库可以单独导出，导入时会按学科和题干去重。

    悬浮控制条为什么有时不见？

    它只出现在课堂里，并且会避开输入区。窗口较窄时会自动排成一行；如果没看到，先确认自己还在课堂页面。

    没有找到相关问题

    换一个关键词试试，比如「报告」「图片」「保存」。

    快捷键 Ctrl / ⌘ + Enter 发送 · Shift + Enter 换行 · Esc 关闭弹窗或抽屉

    这个帮助页是本地静态内容，不会发起网络请求。
